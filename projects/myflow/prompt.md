**Whimsical Widget Wrangler 3000**

Create a Python game where the player cares for a collection of quirky widgets.

Use a list to store widget names (e.g., "Fuzzy Dice," "Singing Spoon").

Each widget has a happiness level (randomly generated).

Players can perform actions (user input): feed, play, or clean widgets.

Actions increase or decrease widget happiness.

The game ends when all widgets reach maximum happiness or one reaches zero.

Use loops to manage actions and happiness levels.  

Expand by adding more widget types, actions, or a scoring system.

Implement a simple menu system for user interaction.

Bonus: Add a whimsical story element!
